Общая информация

В работе были проверены задания по обработке строк в Python.

Проверялись корректные данные и граничные случаи: пустые строки, неправильная длина, неправильный регистр, лишние разделители и некорректные записи.

Задание 1

Проверена строка EKEB-T118.

Проверены длина строки, первые 4 символа, последние 4 символа, символ по индексу и отличие code[9] от code[9:].

Результаты соответствуют требованиям задания.

Задание 2

Проверена функция clean_notice(text).

"EKEB ждёт Т118" после очистки пробелов по краям остаётся "EKEB ждёт Т118".

"Алматы\nАстана\tТараз" преобразуется в "Алматы Астана Тараз".

" " преобразуется в "".

Функция удаляет пробельные символы с краёв и заменяет серии пробельных символов внутри строки одним обычным пробелом.

Задание 3

Проверена функция has_bug(text).

"BUG найден" → True.

"Найден bug" → True.

"DEBUG" → True.

"Всё работает" → False.

"" → False.

Ошибка исходной функции исправлена. Причина ошибки заключалась в неправильной проверке результата find(): значение 0 считается ложным, а значение -1 считается истинным.

Задание 4

Проверена функция valid_nickname(text).

"Aruzhan_7" → True.

"A123" → True.

"Abcdefghijkl" → True.

"A12" → False.

"Abcdefghijklm" → False.

"7Aruzhan" → False.

"Айдана" → False.

" user" → False.

"User-1" → False.

"" → False.

Также проверены граничные случаи длиной 3, 4, 12 и 13 символов.

Задание 5

Проверена функция preview(text, limit).

preview("EKEB приглашает", 10) → "EKEB пр..."

preview(" EKEB ", 4) → "EKEB"

preview("Алматы", 3) → "..."

preview(" ", 3) → ""

preview("ABC", 3) → "ABC"

Дополнительно проверены строки длиной limit - 1, limit и limit + 1.

Задание 6

Проверена функция parse_event(line).

" т118 ; fail ; Ошибка входа " → ["Т118", "FAIL", "Ошибка входа"]

"Т119;PASS;Проверка завершена" → ["Т119", "PASS", "Проверка завершена"]

"T118;PASS;ОК" → None.

"Т118;WAIT;ОК" → None.

"Т118;FAIL; " → None.

"Т118;FAIL" → None.

"Т118;FAIL;а;б" → None.

Функция правильно различает кириллическую Т и латинскую T.

Задание 7

Проверена функция failures(lines, group).

Для группы "Т118" получен результат:

["Ошибка входа", "Ошибка входа"]

Для группы "Т119" получен результат:

["Не открывается профиль"]

Для неизвестной группы получен результат:

[]

Некорректные записи пропускаются. Порядок и повторяющиеся сообщения сохраняются. Исходный список не изменяется.

Задание 8

Проверена функция search_messages(lines, query).

Для запроса " ВХОД " получен результат:

["Вход работает", "Ошибка входа", "Ошибка входа"]

Для пустого запроса получен результат:

[]

Поиск выполняется без учёта регистра. Исходные сообщения не изменяются, порядок и повторы сохраняются.

Дополнительная проверка

Помимо примеров из задания были проверены дополнительные случаи с пустыми строками, неправильными значениями, граничной длиной и некорректными записями.

Все основные проверки выполнены без ошибок.
