Практическая работа «Строки Python»

Ученик: Казмуханбетов Азат Зайдуллаевич

Группа: Т118

Назначение

Практическая работа посвящена обработке строк в Python.

В работе используются:

очистка строк;
изменение регистра;
разделение строк;
поиск подстрок;
проверка символов;
работа с функциями;
обработка записей журнала;
фильтрация сообщений.

Задания

В работе выполнены задания 1–8.

Задание 1

Выполнена работа со строкой EKEB-T118:

определена длина строки;
получены первые 4 символа;
получены последние 4 символа;
получен символ по индексу;
разобрано отличие индекса от среза.

Задание 2

Создана функция clean_notice(text), которая:

убирает пробелы, табуляции и переводы строк с краёв;
заменяет серии пробельных символов внутри текста одним пробелом;
сохраняет регистр и знаки препинания;
для пустого текста возвращает пустую строку.

Задание 3

Исправлена функция поиска BUG.

Поиск выполняется без учёта регистра. Используется проверка наличия подстроки.

Задание 4

Создана функция valid_nickname(text) для проверки ника.

Проверяется:

длина от 4 до 12 символов;
первый символ является латинской буквой;
остальные символы — латинские буквы, цифры или _;
пробелы не удаляются.

Задание 5

Создана функция preview(text, limit).

Функция сначала очищает текст, после чего:

возвращает весь текст, если его длина не превышает limit;
если текст длиннее, оставляет первые limit - 3 символа и добавляет ...;
для пустого текста возвращает "".

Задание 6

Создана функция parse_event(line) для разбора записи формата:

GROUP;STATUS;MESSAGE

Проверяется количество полей, группа, статус и наличие сообщения.

Задание 7

Создана функция failures(lines, group).

Функция находит корректные записи со статусом FAIL для выбранной группы и возвращает их сообщения.

Задание 8

Создана дополнительная функция search_messages(lines, query).

Функция ищет сообщения по запросу без учёта регистра и сохраняет порядок и повторения сообщений.

Запуск

Открыть файл text_tools.py и запустить его в Python.

После запуска выполняются демонстрационные вызовы функций и выводятся результаты проверок.
